# Overdrive

A local media library for videos, images, audio and text: custom metadata
("chips"), deep tags and filters, visual previews. Native Rust desktop app
built with iced and colony-ui, part of Project-Colony.

**Status:** early rewrite, nothing to install yet. See
[docs/project/roadmap.md](docs/project/roadmap.md).

## Origin

Overdrive is a rewrite of [MediaChips](https://github.com/fupdec/MediaChips)
by the MediaChips contributors. The upstream source, as of commit
`d7554a9526f713f6be93b31f5313c1ad322537dd` (v1.12.0), is kept unmodified in
[`reference/mediachips/`](reference/mediachips/) for study. It is never
compiled into Overdrive.
